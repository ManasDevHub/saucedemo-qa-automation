# Defect Records: Login Module

Actual defects identified during manual testing will be added here.

## Logging Guidelines
When a genuine defect is discovered during the manual verification of the Login module:
1. File an entry in the root defect tracker: `defects/Bug_Report.xlsx`.
2. Create an individual markdown report in this folder following the naming convention:
   `BUG-[ID]-[short-description].md` (e.g., `BUG-001-invalid-login-error.md`).
3. Store corresponding visual evidence (screenshots, recordings) in:
   `screenshots/Login/BUG-[ID].png`.
4. Update the Requirement Traceability Matrix (`docs/rtm/RTM.xlsx`) to cross-reference the failed test case and Bug ID.

*No simulated or placeholder defects are created in this folder.*
